# HisabSathi MVP Launch Plan

This launch plan keeps the first release focused on real shared-money behavior, not advanced automation.

## Target Users

- College friend groups.
- Hostel students.
- Roommates.
- Travel groups.
- Office lunch groups.

## First 20 Users Plan

1. Invite 5 trusted friends who regularly split food, travel, or hostel expenses.
2. Ask each of them to invite 2 to 3 people from one real expense group.
3. Onboard everyone through one short message with the local or deployed app link.
4. Ask every group to add at least 3 expenses and complete at least 1 settlement.
5. Collect feedback within 24 hours of their first settlement.

## First 5 Groups To Test With

- One college friend group.
- One hostel or roommate group.
- One travel group planning or finishing a trip.
- One office lunch or snack group.
- One mixed group with loans and shared expenses.

## Feedback Questions

- What did you use HisabSathi for first?
- Was it clear who owed whom?
- Did the payment proof and confirmation flow make sense?
- Was adding a group member understandable?
- Did custom split totals feel easy or confusing?
- Did dashboard numbers match what you expected?
- What stopped you from adding another expense?
- Would you invite your real friends or roommates?

## MVP Success Metrics

- Number of groups created.
- Number of expenses added.
- Number of settlements completed.
- Number of users returning after 7 days.
- Number of users inviting friends.
- Number of payment disputes reduced.

## What To Track Manually

- User name and group type.
- Date invited.
- Whether they registered.
- Number of groups created.
- Number of expenses created.
- Number of settlements marked paid.
- Number of settlements confirmed.
- First confusion point.
- Most requested feature.
- Whether they returned after 7 days.

## What Not To Build Yet

- Official eSewa or Khalti integration.
- Push notifications.
- SMS reminders.
- Receipt OCR.
- AI expense categorization.
- Trip mode.
- Roommate mode.
- Smart settlement simplification.
- React Native mobile app.

## Next Feature Priorities

1. Improve member discovery so users do not need numeric user IDs.
2. Add settlement simplification after real split behavior is validated.
3. Add durable production media storage for proof images.
4. Add notification channels after reminder engagement is proven.
5. Prepare official payment gateway integration only after manual proof flow is trusted.

## Launch Rule

Do not add advanced features until the first 20 users complete real groups, expenses, settlements, and feedback. Stability, clarity, and trust are the MVP priorities.
